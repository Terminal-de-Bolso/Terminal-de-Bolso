Firefox 160: Janela Flutuante (Mini Window) e Controles no PiP

A Mozilla lançou o Firefox 160, e esta versão traz melhorias bem práticas para o uso diário, focando em multitarefa, desempenho e novos recursos multimídia. ​Se costumas navegar mantendo vídeos ou páginas de lado enquanto trabalhas, vais gostar das novidades. ​🪟 Nova "Mini Window" (Janela Flutuante) ​A grande novidade desta versão é o modo Mini Window (ainda em fase de testes/beta). Podes destacar uma aba inteira ou selecionar apenas uma parte específica de uma página web para flutuar num painel sempre no topo (always-on-top) enquanto navegas por outros conteúdos. ​Para usar, podes personalizar a barra de ferramentas adicionando o ícone da Mini Window, ou clicar com o botão direito numa secção da página e escolher a opção de mover para a janela flutuante. ​⚡ Controles de Velocidade no Picture-in-Picture (PiP) ​O modo PiP do Firefox finalmente recebeu um ajuste muito pedido: botões diretos para controlar a velocidade de reprodução de vídeos (variando entre 0.25x e 2.0x), diretamente na janelinha flutuante do vídeo, desde que o leitor tenha espaço suficiente para exibir os controles. ​🛠️ Outras Melhorias Técnicas ​Reconhecimento de Voz Local: Suporte à API Web Speech para conversão de fala em texto (speech-to-text) diretamente no dispositivo, cobrindo 40 idiomas sem enviar dados de áudio para servidores externos. ​Suporte a MKV: O browser agora reproduz nativamente ficheiros Matroska (MKV) contendo faixas de áudio FLAC, MP3 ou PCM. ​Metal API no macOS: A renderização de conteúdos WebGL no macOS passou a utilizar a API gráfica Metal da Apple, trazendo ganhos de desempenho em páginas pesadas. ​Correções de Bugs: Resolução de engasgos irritantes ao autenticar em sites de intranet usando protocolos NTLM ou Kerberos, além de melhorias na precisão ao selecionar textos no telemóvel. ​O update já está a ser distribuído gradualmente para utilizadores de Windows, macOS e Linux.
